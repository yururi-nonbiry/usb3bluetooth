# usb3bluetooth (ESP32-S3 USB to BLE Bridge)

ESP32-S3を使用して、有線USBキーボードやマウスをBluetooth (BLE) で接続できるようにするアダプターです。

## 主な機能
- **マルチデバイス対応**: 最大4台のデバイスとペアリングし、即座に切り替えて使用できます。
- **キーボードでの切り替え**: 接続されたキーボードのショートカットキーでデバイスを切り替え可能です。
- **ステータス表示**: 内蔵フルカラーLEDにより、現在選択されているスロットや接続状態を確認できます。

## デバイスの切り替え方法
以下の3つの方法で接続先（スロット）を切り替えることができます。

1. **本体ボタン**: ESP32-S3のBOOTボタン（GPIO 0）を短押しするごとにスロットが切り替わります。
2. **キーボードショートカット (通常キーボード向け)**:
   - `Alt + F1`: スロット1
   - `Alt + F2`: スロット2
   - `Alt + F3`: スロット3
   - `Alt + F4`: スロット4
3. **カスタムキー (Keyball / QMK向け)**:
   - `F13`: スロット1
   - `F14`: スロット2
   - `F15`: スロット3
   - `F16`: スロット4

## LEDの状態
スロットごとに色が割り当てられています。
- **スロット1**: 赤 (Red)
- **スロット2**: 青 (Blue)
- **スロット3**: 黄 (Yellow)
- **スロット4**: 緑 (Green)

- **点灯**: Bluetooth接続済み
- **点滅**: ペアリング待機中 / 未接続

## 特殊操作
本体ボタン（GPIO 0）を長押しすることで、リセット操作が可能です。

- **長押し (2秒〜5秒)**: **現在のスロットのみ**をリセットします。
  - LEDが**白**く高速点滅します。ボタンを離すと、現在のスロットのペアリング情報が削除され、再起動します。
- **超長押し (5秒以上)**: **全てのペアリング情報と設定**をリセットします（工場出荷状態）。
  - LEDが**赤**く高速点滅します。ボタンを離すと、全ての設定が初期化され、再起動します。

## 開発環境
- PlatformIO (ESP32-S3-DevKitC-1)
- NimBLE-Arduino
- EspUsbHost
